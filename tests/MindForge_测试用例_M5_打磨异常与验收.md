# MindForge 测试用例 · M5 打磨、异常与验收

> 阶段目标：异常全覆盖（未选场景/档位、空提交、AI 中断、网络超时、超长压缩）→ 帮助中心 → 响应式三断点 → 无障碍 → 性能 → 隐私可见化。
> 对应需求：AC-05/AC-06/AC-07、FR-08、UI/UX §7、非功能性能。

## 1. 异常与健壮性（AC-05/06/07）

| 编号 | 对应需求 | 操作 | 预期结果 | 通过标准 |
|---|---|---|---|---|
| M5-TC01 | AC-05 AI 中断 | 对话中模拟生成失败（关闭 Mock 且断网） | 非阻断横幅「生成出错，请重试」+ 重试按钮，不崩溃、不丢上下文 | 可恢复 |
| M5-TC02 | AC-06 网络超时 | 首字 >2s 未达 | 横幅「网络超时，请检查网络后重试」，保留已输入内容 | 可重试 |
| M5-TC03 | AC-07 超长压缩 | 发送 > MAX_TURNS(40) 轮 | 后端压缩历史（注入精简头），前端 toast「已为你精简上下文」，角色一致性保持 | 无感压缩 |
| M5-TC04 | AC-01/02 前置 | 未选场景/档位进入 | 内联提示阻止 | 同 M1 |
| M5-TC05 | AC-03 空提交 | 空白发送 | 微震 + 提示，不调模型 | 同 M1 |
| M5-TC06 | 客户端兜底 | `MetricsEngine.init` 拉取 `/api/config/filler` 失败 | 回退内嵌词典，指标仍可用 | 离线可用 |

## 2. 功能与体验（FR-08 / UI/UX）

| 编号 | 对应需求 | 操作 | 预期结果 | 通过标准 |
|---|---|---|---|---|
| M5-TC07 | FR-08 帮助中心 | 点帮助 | 抽屉展示：定位/流程/施压机制/护栏/隐私 | 内容完整 |
| M5-TC08 | FR-08 隐私可见化 | 训练区/帮助 | 教练侧栏常驻「本地处理·数据可删除」标识 | 可见 |
| M5-TC09 | AC-12 数据管理 | 点导航「数据管理」 | 列出本地会话，可单条删除/清空 | 可删除 |
| M5-TC10 | UI/UX 响应式·桌面 | ≥1024px | 左对话 65% + 右教练 35% 双栏 | 双栏 |
| M5-TC11 | UI/UX 响应式·平板 | 768–1023px | 教练侧栏折叠为抽屉，可展开 | 抽屉 |
| M5-TC12 | UI/UX 响应式·移动 | <768px | 单栏，档位自适应，护栏底部，Hero 缩放 | 单栏 |
| M5-TC13 | UI/UX 无障碍 | 键盘 | 焦点环可见(2px 强调色)；确认弹窗 `role=alertdialog` | 可达 |
| M5-TC14 | UI/UX 无障碍 | `prefers-reduced-motion` | 关闭逐字/视差，改整段淡入 | 尊重设置 |
| M5-TC15 | UI/UX 色彩合规 | 全站 | 浅主色、深青绿唯一强调、墨色止于 #2B2B2B、无纯黑主色 | WCAG AA |

## 3. 性能（非功能）
- M5-TC16 首屏 < 2s：纯静态前端 + 轻量 CSS。
- M5-TC17 流式首字 < 2s（AC-04）。
- M5-TC18 报告 < 10s（AC-10）。
