# MindForge 测试用例 · M2 教练与实时指标

> 阶段目标：前后端正则统计（填充词频次/平均句长/停顿语速）→ 教练侧栏阈值色 → 每轮 1–3 条建议（LLM 补定性）→ 指标与建议并发生成不阻塞。
> 对应需求：FR-04/FR-07、UI/UX §4.3/§5.8。

## 2. 接口级验证
- `POST /api/coach/feedback` body `{"user_reply":"然后嗯我觉得就是说这个然后那个不太行"}` →
  `{"metrics":{"filler_per_k":111,...},"advice":["填充词（嗯/然后/就是说）偏多，先亮观点再展开细节。"]}`
- 阈值：`<15` 绿 / `15–30` 黄 / `>30` 红；句长 `10–42` 绿，`<10` 红(碎)，`>42` 黄(长)。
