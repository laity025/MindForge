# MindForge 测试用例 · M1 核心对话闭环

> 阶段目标：场景选择 → 档位选择 → 面试官 SSE 流式开场/追问（首字<2s）→ 用户文本作答 + 空提交拦截 → transcript 黑板累积 → 单轮单角色。
> 对应需求：FR-01/FR-02/FR-03、AC-01/AC-02/AC-03/AC-04。

## 1. 测试用例

| 编号 | 对应需求 | 前置 | 操作 | 预期结果 | 通过标准 |
|---|---|---|---|---|---|
| M1-TC01 | AC-01 场景前置 | 首页 | 未选场景直接点「开始训练」 | 配置弹层打开且「进入模拟」禁用，内联提示需先选场景 | 不可进入训练 |
| M1-TC02 | AC-02 档位必选 | 已选场景未选档位 | 点「进入模拟」 | 按钮禁用 + 提示「请选择施压档位」 | 不可进入 |
| M1-TC03 | FR-01 场景选择 | — | 选「考研复试」/「校招面试」 | 卡片高亮选中，配置项正确回填 | 视觉选中态 |
| M1-TC04 | FR-02 三档施压 | — | 选 温和/标准/高压 | 分段控件选中态填充语义低饱和色（绿/蓝灰/琥珀） | 选中态清晰 |
| M1-TC05 | AC-04 流式首字 | 已进入模拟 | 触发面试官首条发言 | SSE 首个 `data:{"delta":...}` 在 2s 内到达并逐字上屏 | 首字 < 2s |
| M1-TC06 | FR-03 开场+追问 | 标准档 | 观察开场白与后续追问 | 每次仅一个问题，保持高压节奏 | 单问题/轮 |
| M1-TC07 | AC-03 空提交拦截 | 训练区 | 输入框空白点「发送」/Enter | 输入框微震 + toast「请输入内容后提交」，且不调用模型 | 不发请求 |
| M1-TC08 | 单轮单角色 | 面试官生成中 | 生成期间点发送 | 发送被禁用（textarea disabled + guard busy），无法污染角色 | 不并发 |
| M1-TC09 | 黑板累积 | 多轮对话 | 发送多条用户作答 | 每条 user/interviewer 进入 `TranscriptStore.transcript`，下次请求上送后端 | 历史正确累积 |
| M1-TC10 | 档位语义 | 高压档 | 面试官发言 | 冷峻追问但无侮辱性语言（Prompt 铁律约束） | 不越界 |

## 2. 接口级验证（可脚本化）
- `POST /api/chat/interviewer`：`transcript:[]` → 返回开场白流式；`transcript` 含历史 → 返回追问。
- 首字延迟：curl 测得首个 `delta` 事件 < 2s（Mock 即时；真实 API 受 TIMEOUT_MS 约束）。
